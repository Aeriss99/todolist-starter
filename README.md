# Todolist
Aplikasi pencatat tugas sederhana.

Template Proyek Akhir Git & GitHub di BisaNgoding.com. Klik **Use this template** untuk membuat repo milikmu.

- `index.html`: halaman aplikasi (bisa diterbitkan dengan GitHub Pages)
- `todo.js`: fungsi-fungsi todo
- `todo.test.js`: tes, dijalankan dengan `npm test`
- `.github/workflows/ci.yml`: menjalankan tes setiap push dan pull request
